# 乖乖待在我身边学微积分

一个用纯 HTML/CSS/JS 写的分支剧情小游戏（恐怖/病娇向视觉小说），取材自"乖乖待在我身边学XX"系列梗。深夜空教室里，一位执着的"老师"把你困在教室，逼你一道题一道题地学微积分——你的选择和答题情况会影响"好感度"，并最终决定三种不同的结局。

没有任何构建步骤、依赖或后端，就是一个静态 `index.html`，用浏览器直接打开就能玩。

## 玩法

- 点击对话框，或点击右下角的 `>` 按钮推进台词；`<` 按钮可以回看上一句。
- 剧情中会出现选项按钮，选择不同选项会影响剧情走向和好感度。
- 右上角显示好感度（爱心数量，0~10），部分台词/选项会让好感度增加或减少。
- 做完三道题后，根据最终好感度进入三种结局之一：
  - 好感度 ≥ 8 —— 永恒课堂
  - 3 ≤ 好感度 < 8 —— 无限循环
  - 好感度 < 3 —— 下课

完整剧本见 [script.txt](script.txt)。

## 本地运行

直接用浏览器打开 `index.html` 即可，不需要任何安装或构建：

```bash
# 任选一种方式
open index.html          # macOS
start index.html         # Windows
```

## 部署到 GitHub Pages

1. 把本项目推到一个 GitHub 仓库（仓库根目录就是 `index.html` 所在目录，或者放进 `/docs` 文件夹）。
2. 进入仓库 `Settings → Pages`。
3. Source 选择 `Deploy from a branch`，Branch 选择 `main`（或 `master`），目录选择 `/ (root)`（或 `/docs`，取决于第 1 步）。
4. 保存后等几分钟，GitHub 会给出一个 `https://<你的用户名>.github.io/<仓库名>/` 的访问地址。
